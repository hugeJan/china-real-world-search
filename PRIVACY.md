# Privacy Policy

_Last updated: 2026-08-23_

China Real-World Search is a skills-only ChatGPT/Codex plugin maintained by `hugeJan`. The plugin package contains instructions and reference files. It does not operate its own server, account system, database, analytics endpoint, or authentication flow.

## Data handled by the plugin developer

The plugin does not directly collect, store, sell, or transmit personal data to the developer. There is no developer-operated MCP server or external API in version 1.0.0.

## Data handled by ChatGPT, Codex, and third-party services

When the plugin is used, ChatGPT or Codex may process the user's prompt and may use capabilities available in the host product, such as web search or installed apps, according to the user's OpenAI plan, workspace settings, permissions, and the applicable OpenAI terms and privacy policy.

If a workflow leads the user to a third-party website, app, mini program, map, ticketing system, government service, or other platform, that third party's own privacy terms apply. The plugin does not bypass login, CAPTCHA, permissions, or access controls.

## Sensitive information

Users should avoid putting unnecessary passwords, authentication tokens, government ID numbers, payment credentials, precise private addresses, medical records, or other sensitive information into prompts or public search fields. The skill explicitly instructs the assistant not to collect unnecessary personal or private data.

## Changes

Material changes to this policy will be committed to this repository with an updated date.

## Contact

For privacy questions, open an issue at the repository's public issue tracker: https://github.com/hugeJan/china-real-world-search/issues
