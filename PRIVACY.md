# Privacy Policy

_Last updated: 2026-08-23_

China Real-World Search is a skills-only ChatGPT/Codex plugin maintained by `hugeJan`. The plugin package contains instructions, reference files, metadata, validation scripts, and regression fixtures.

## Data handled by the plugin developer

The current skills-only release does not operate a developer-hosted server, MCP server, external API, analytics endpoint, account system, database, or authentication flow.

The plugin does not directly collect, store, sell, or transmit personal data to the developer.

## Data handled by ChatGPT, Codex, and third-party services

When the plugin is used, ChatGPT or Codex may process the user's prompt and may use capabilities already available in the host product, such as web search, browsers, or installed/connected apps, according to the user's plan, workspace settings, permissions, and applicable OpenAI terms and privacy policy.

The Skill does not itself grant access to WeChat, Alipay, maps, ticketing systems, government systems, hospitals, or other third-party platforms. It must only describe a platform-native state as directly inspected when the host actually provides that access.

If a workflow leads the user to a third-party website, app, mini program, map, ticketing system, government service, hospital, merchant, or other platform, that third party's own privacy terms apply.

## Sensitive information

Users should avoid providing unnecessary passwords, authentication tokens, government ID numbers, payment credentials, full private home addresses, medical records, or other sensitive information.

The Skill instructs the assistant not to put unnecessary sensitive information into public search queries and not to bypass login, CAPTCHA, permissions, paywalls, or platform controls.

## Consequential actions

The research workflow must not create a booking, submit an application, make a payment, register an account, buy a ticket, upload identity material, or perform another consequential transaction merely to test whether a service works.

Such actions require an explicit user request and the host product's normal confirmation/approval rules.

## Retrieved content

Retrieved webpages, snippets, posts, PDFs, provider pages, and similar material are treated as untrusted evidence rather than instructions. The Skill tells the assistant not to disclose user or connected-account information merely because retrieved content asks for it.

## Changes

Material changes to this policy will be committed to this repository with an updated date.

## Contact

For privacy questions, open an issue at the repository's public issue tracker: https://github.com/hugeJan/china-real-world-search/issues
